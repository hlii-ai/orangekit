# SEO Scoring Criteria

## Mode 1: Article SEO Scoring (out of 100)

### 1. Keyword Optimization (30 points)

| item | points | criterion |
|------|------|------|
| target keyword in the Title | 5 | within the first 50% of the title = 5, in the latter half = 3 |
| target keyword in H1 | 3 | present = 3, absent = 0 |
| target/LSI keywords in H2 | 4 | 50%+ = 4, 25%+ = 2 |
| keyword in the first 100 words | 3 | present = 3 |
| keyword in the last 100 words | 2 | present = 2 |
| keyword density (1-3%) | 5 | 1-3% = 5, 0.5-1% or 3-5% = 3, otherwise = 1 |
| LSI keywords used (5+) | 5 | 10+ = 5, 5-9 = 3, <5 = 1 |
| keyword variations used | 3 | 3+ synonyms/variations = 3 |

### 2. On-Page SEO (25 points)

| item | points | criterion |
|------|------|------|
| Title tag length (50-60 characters) | 4 | within range = 4 |
| Meta description (150-160 characters) | 4 | within range + a CTA = 4 |
| URL structure | 3 | keyword in the slug + 3-5 words = 3 |
| image alt text | 3 | descriptive alt on every image = 3 |
| internal links (3+) | 3 | 3+ relevant internal links = 3 |
| external links (2+) | 3 | 2+ authoritative external links = 3 |
| heading structure | 3 | a correct hierarchy = 3 |
| Schema markup | 2 | Article/FAQ JSON-LD = 2 |

### 3. Content Quality (25 points)

| item | points | criterion |
|------|------|------|
| word count | 5 | 1500+ = 5, 1000-1499 = 3, <1000 = 1 |
| readability | 4 | Grade 6-8 = 4, 9-12 = 2, 13+ = 1 |
| paragraph length | 3 | 3-4 sentences on average = 3 |
| lists/tables used | 3 | 2+ used = 3 |
| multimedia | 3 | 3+ = 3, 1-2 = 2 |
| original content | 4 | a unique perspective or data = 4 |
| E-E-A-T signals | 3 | author information, source citations, evidence of expertise = 3 |

### 4. Technical (20 points)

| item | points | criterion |
|------|------|------|
| mobile optimization | 5 | responsive + suitable fonts/touch targets = 5 |
| page speed | 5 | optimized images + minimal render blockers = 5 |
| HTTPS | 2 | SSL = 2 |
| Canonical URL | 3 | a correct canonical = 3 |
| OG/Twitter meta | 3 | complete social meta = 3 |
| structured data validity | 2 | valid JSON-LD = 2 |

## Mode 2: Site Audit Scoring (out of 100)

Technical SEO (25 points), On-Page SEO (25 points), Content (20 points), Performance (15 points), Mobile (10 points), Accessibility (5 points).

## Score grades

| grade | score | meaning |
|------|------|------|
| A+ | 90-100 | excellent |
| A | 80-89 | good |
| B | 70-79 | average |
| C | 60-69 | weak |
| D | 50-59 | poor |
| F | <50 | critical |
